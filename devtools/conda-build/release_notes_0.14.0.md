# Sabueso 0.14.0 — Consolidated native knowledge and scientific journeys

Release candidate under qualification. Stable publication requires exact-source
CI/governance and all twelve installed OS/Python lanes for one immutable staged
Conda archive. Publication, public installation and Zenodo archival are separate
gates; preceding source receipts do not establish them.

## Knowledge access and explicit scientific context

- Add bounded native clients, mappings and explicitly bound supplied-file readers
  across structural, sequence, interaction, disease and chemical sources. Source
  registration distinguishes native access, card contribution and evaluated gaps.
  A native client does not imply an enricher, current online qualification or a
  licence to redistribute its inputs.
- Add exact source-sequence and isoform retrieval, canonical residue tracks,
  supported residue knowledge and rule-labelled composition summaries. Preserve
  original numbering, uncertain bounds, molecule scope and sequence revision.
  Similarity, matching names or residue numbers never merge identity; incompatible
  axes remain unplaced or uncomputed.
- Add reproducible notebook reports and a public HK2 test system rebuilt from the
  original public UniProt response. Historical exploratory cards, ligand hints and
  private pilot material do not become current scientific knowledge.
- Write additive card schema **0.3.13**: native UniProt regulation, domain notes,
  similarity, cautions and miscellaneous text, and additional positional chain,
  lipidation, motif, region, sequence-conflict, topology and membrane fields.
  Every value retains assertion support. Published schemas and historical pins
  remain unchanged and readable; migration reports optional refresh gaps.

## Traceability, clinical bibliography and integrity

- Extend acquisition observation to the bounded disease/clinical routes and NCBI
  Taxonomy. Preserve exact requested scopes, pages, response identities, original
  retrieval time, replay/reuse and completed versus missing/unavailable outcomes.
  Acquisition coverage reaches 35 source families; complete built-in/custom-source
  and bibliography coverage remains open in #108.
- Preserve native ChEMBL trial/publication pointers, explicit ClinicalTrials.gov
  study/reference requests and original Europe PMC collective authors. Bibliography
  never follows unasked links or turns a registry statement into clinical Evidence.
- Preserve conservative MONDO, Orphadata, DISEASES and NCBI disease identity,
  release/time and incomplete-answer behavior. Disease-deck support rejects foreign
  member identities; source terms retain explicit admission/exclusion reasons.
- Report missing organism fixtures as unavailable, retaining partial taxonomy
  support. A missing local answer is not a biological absence statement. Genuine
  evaluated-empty online answers keep their separate outcome.

## Independent scientific journeys and publication boundaries

- Exercise separate producer, inert reader and reacquisition processes for protein
  comparison, molecule/activity and bounded disease/entity journeys. Original card,
  deck and packet pins, supporting assertions, quantities, bibliography and portable
  runtime sidecars remain intact. Readers add no source access or execution credit.
- Deliver only reviewed repository inputs. Protected local-only originals stay
  outside Git, public CI and release archives; independently qualified native input
  tests remain a separate opted-in local receipt.
- Python 3.11–3.14; Linux, macOS Apple Silicon and Windows require installed release
  qualification. Ackredit >=0.9.0 and the exact public minimum dependency closure
  remain unchanged. The only public package route is the noarch Conda archive.

## Known limits

Complete private MOLI consumer routes remain open (#132); the bounded identity and
original-reader checks do not establish full pilot acceptance. Nextia Evidence and
shared MOLI record interpretation remain consumer/platform responsibilities.
Python 3.14 reports unclosed SQLite connections during repository validation (#133);
the owner and lifetime still require investigation, and no warning is suppressed.
The previous large process-memory counter does not establish a Sabueso allocation
peak (#98); instrumented Linux identity runs remain bounded diagnostic receipts.
Recorda integration, unrestricted extraction, complete live source health and
licence-dependent provider access remain outside this release's qualified scope.
