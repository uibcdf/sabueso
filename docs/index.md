## Install

Sabueso is distributed through the `uibcdf` conda channel:

```bash
conda install -c uibcdf -c conda-forge 'sabueso>=0.4.0'
```

The latest release is 0.4.0 (card schema 0.3.4). To work on Sabueso itself, see `Developers`.
