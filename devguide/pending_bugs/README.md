# Pending Bugs

Durable issue-backed bug analyses live here when they need multi-session evidence
or reasoning. Some reports retain a resolved bounded correction alongside
historical limits or later acceptance; folder membership does not mean the fix
is unimplemented. Read each report's status, source receipt and remaining scope.
Every report must reference its owning GitHub issue and follow the MOLI reporting
protocol.

[CHECKPOINT](../CHECKPOINT.md) owns current qualification, and the
[destination action plan](../CONTINUATION_PLAN_20261104.md#destination-review-and-next-actions)
owns immediate work. Preserve original failure/receiving records; do not reopen
a completed correction solely because an older paragraph described it as pending.
