molecule → supplied protein Card → measured molecules. The receiving molecule
predicate expects the 17-route protein menu from its original development epoch,
while the current producer retains 21 routes, including variants, sequence
changes, comparative context and associations. It raises `Saved original protein
destination routes differs from its original molecule binding.`

`cd98ad685ea9f678f48dabe60e8d7e91503435e1`, runtime
`0.14.0+245.gcd98ad6`, with the original unchanged test. This establishes a local
pre-existing integration defect, not a new source assertion or a clean public-
package prevalence claim. Shared dependencies remain editable in that diagnostic.

route catalog. The complete descriptions must match the independently frozen
SDK243 catalog, exact registered literal metadata and captured protein nature.

their receiving choice even when catalog values coincide.

link, explicit target capture, molecule/target pins, incoming navigation, typed
selection, original context, source/back path and display operation. Original
molecule science and earlier catalog verifiers stay fixed; co-retained earlier
menus still use their owning predicate. A menu never executes an unobserved
scientific topic. Unexecuted requests remain `not_saved`.

Owning controls include plain opening/topic menus without science, shared storage/
resave, source-owned lookalikes, resealed label/membership/focal-context changes,
the public molecular target menu and the complete molecule LIVE cohort. The
