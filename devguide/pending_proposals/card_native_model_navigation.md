# Native model reference-interval navigation

## Researcher task

From a retained native predicted model, ask **which retained experimental
structures describe its explicitly declared reference interval?** Open the model's
related context, inspect the prepared question and follow it. The answer retains
the same captured protein, region, source support and return route. Human browsing
never downloads models or refreshes a Card.

The public AF-Q8WZ42-F2 model declares entity positions 1–1400 against UniProt
Q8WZ42 positions 201–1600. The separate original-reference finding checks native
sequence and reference CRC64 against coherent original sequence, length and
checksum statements. New `native_model_structure_request@1` also requires those
exact statements and values to remain selected in the captured Card. A matching
label or a replacement statement with an equal value is insufficient.

`retained_context_links@8` exposes one explicit question alongside original source
and endpoint links. Its request shares `region_coverage` with existing human
answers and the compact agent structures inventory. Proper native fragments set
`include_fragments=True`; whole-reference intervals set it to `False`. A valid
request may return an empty retained inventory. That is not global structural
absence and does not initiate acquisition.

The researcher sees original declared interval, sequence/reference support and
remaining unknowns. Original UniProt sequence-update date is not retained in the
focal statements: date agreement stays unknown. Sequence agreement never proves
entity identity by similarity, observed atoms, experimental equivalence, chain
correspondence or biological assembly relevance. Qualifier conflicts, missing or
unverifiable original findings and changed captured selections expose an unavailable
question with its reason, rather than silently selecting another interpretation.

## Original saved reading

New sessions containing native question navigation use
`sabueso.card_exploration@12` / `native_model_navigation_binding@1`.
Declaration and native/reference predicates are frozen from SDK182 source
`a03bdbd`, independently of current mappers and the optional CIF parser. The
verifier checks original findings, source closure, exact prepared requests and
retained navigation; it does not replace stored output or establish source truth.
Formats @1–@11, API contexts/questions, native declaration/context rules, packet
mappings and Card schema remain unchanged.

A visited destination reopens its original result. An unvisited question returns
`not_saved`; reading cannot run it under current science. Mixed sessions preserve
older API, shared support and assembly navigation policies. Literal original
SDK181 metadata and SDK182 finding-only captures retain their original meanings.
