# Complete shared support for source-heavy fields

The full public Q8WZ42 [save failure](../pending_bugs/large_sequence_panel_save.md)
comes from materializing related links before freezing views. Each original
source row copied the entire field's list of supporting statements. A bounded
cProfile control stops at 512 MiB after 21 explanations/20 link operations,
before freezing any view. Related navigation accounts for 17.355 of 18.069
profiled preparation seconds and deep copies for 16.074 cumulative seconds;
these overlapping measurements cannot be added or treated as unprofiled latency.

## Representation and applicability

Generic navigation with at least two distinct original statement IDs uses
`retained_context_links@7`. It creates one metadata object containing
`retained_link_support@1`, the exact originating location and the entire original
support list. Each source row keeps its original ID, order, availability and
destination, with a small membership descriptor:

- `basis`: `retained_support_membership`;
- `rule`: `retained_link_support@1`;
- `support_location`: the typed, content-bound location of the complete object;
- `statement_id`: that exact original statement ID, or null for an endpoint's
  membership in the whole supporting basis.

No source rows, missing references, derivation inputs, alternatives, conflicts or
captured Cards are discarded. Equal values do not merge entities or observations.
Duplicate-reference inputs retain the preceding policy instead of silently
choosing one. The one-reference path and specialized annotation/model policies
remain original; this is a named navigation policy, not a new scientific finding
or SourceAssertion. The intermediate generic metadata construction is not kept
as an extra navigation view for @7; its complete object remains retained.

For humans, a source row still opens the exact original source record, and the
original field's `explain()` still opens its complete source support. Return paths
and labels stay usable. For an agent, the row's typed `support_location` is read
through `explorer.access.read(location)` or `explorer.inspect(locator=location)`.
The complete list remains accessible on demand without repeating it per row.
Public payload/support getters retain defensive copying.

## Original saved reading

Sessions containing @7 navigation use `sabueso.card_exploration@11` and
`shared_link_support_binding@1`. The new independent verifier preserves all
preceding bindings, adding complete shared-basis/source-location verification,
exact ordered membership, missing-state refusal, original destination/identity
decisions and per-item/cell support checks. Live navigation and current scientific
producers are not called during saved reading. The @11 verifier has its own
frozen predicates; formats @1–@10 and their fixtures/verifiers are unchanged.
Native result support additionally requires its verified scientific originating
view, exact result identity and focal snapshot. A literal metadata object carrying
an adapter label cannot supply native support. A reidentified lookalike control
reproduces the initial candidate's missing admission check; the final refinement
rejects it and separately accepts a genuine public native result.
Mixed original annotation/model, structure, assembly, component, quaternary and
site decisions retain their original individual policies inside the new session.

The Card schema, physical quantities, scientific defaults and transport codecs
are unchanged. Default byte/window budgets, atomic destination preservation and
explicit deliberate overrides retain their existing public contract.
