# Structure declaration to assembly question

`structure_declaration_context_links@2` retains the original @1 field/source/
endpoint decisions and adds one explicit assembly-generation question. It accepts
the exact native inventory item, literal focal `has_structure` relationship or
its qualifier node. `structure_assembly_request@1` retains that typed parent
location and prepares both `structure_ref` and `relationship_id`, compact expansion
flags and the original visible operation budget. A supported declaration may lack
generation inputs; its answer reports that missing retained scope. Unsupported
structure identifiers have an inspectable unavailable question rather than a guess.

Listing links performs no assembly evaluation. Following the ready question uses
the shared human/agent captured result cache. Matching PDB labels never merge
relationships, supplied Cards or revisions. Source support stays attached to the
original relationship; native ambiguity and physical unknowns remain unchanged.
This route neither queries sources nor assigns ligands/contacts to physical copies.
