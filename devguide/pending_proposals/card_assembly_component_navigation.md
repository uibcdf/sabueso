declaration, then opens its declared component positions and their original
records/sources. Version identifiers are carried internally in explicit requests;
the researcher navigates ordinary questions and links. Native key resolution,
declaration counts and physical membership remain separate. No geometry, contact
assignment, chemical equivalence or identity by shared author labels is inferred.

scope with an explicit native @5 choice. Direct Card/explorer defaults remain @4;
old saved questions keep their own request and destination. Listing a question
does not evaluate science. Following it shares the existing captured @2 result
with the equivalent agent request, including unknown/partial original input.

policies @1 expose each original declaration position separately, retaining
repeated/unrecognized labels, native binding state, original registry records,

not establish a resolved component or a physical molecular copy. Agents can read
the same typed requests, locations and complete retained payload with bounded pages.
