Owner: [Sabueso #83](https://github.com/uibcdf/sabueso/issues/83); account/key access
follow-up: [#95](https://github.com/uibcdf/sabueso/issues/95). Local review: 2026-10-08.
On 2026-10-08 the maintainer confirmed that no authorized access or original input
is currently available and asked to retain these future needs independently of
eventual stash deletion. This maintained document and the authoritative registry
retain those needs; historical source code, the stash and `/tmp` receipts are not
prerequisites for reopening a provider. No stash deletion is performed here.

These are useful sources set aside with specific external triggers, not active
implementation work, retired resources or new scientific assertions. This list is
limited to the recovered candidate set; other registry evaluations remain separate.

[REST documentation](https://www.guidetopharmacology.org/webServices.jsp) still

requires agreement and manual processing; Open and Limited Database rights differ.

with licensed commercial reuse/redistribution and a printed 2025 date: browser
readability is not current-release access or a new grant.

original `/tmp/sabueso-followup18-asd-download.js` is the download-condition evidence
(research-only, no third-party redistribution, licence/login gating). The browser
cannot read this linked JavaScript MIME type; no new grant or dataset is inferred.
ELM's [downloads](https://elm.eu.org/downloads.html), academic licence and homepage
again yield browser errors/timeouts. Previous bounded native HTTPS timeout remains
`/tmp/sabueso-followup20-access.json`; no export or agreement was received. The
original provider's 2016 paper describes downloadable data, but it does not supply
current files or a current exact agreement.
CASTpFold's [tutorial](https://cfold.bme.uic.edu/castpfold/infos/allabout/tutorial.html)
and [local visualization guide](https://cfold.bme.uic.edu/castpfold/infos/allabout/Local%20visulization.html)
are readable and describe existing-result `.poc`/`.pdb` files. They do not supply a
received native result or establish dataset redistribution rights. Existing shell/
failed-route receipts are retained; no failed scientific result route was retried.

No account creation, licence assent, registration request, provider message, gated
download, invented API, TLS workaround, structure upload or new scientific job.
Environment-variable checks inspect only presence, never secret values. None of the
five conventional source key variables is configured; this does not claim that no
maintainer holds access elsewhere. No native fixture exists for any of the seven.
A maintainer's authorized original artifact or access can reopen the relevant case.

Once a named condition changes, qualify the original native identity, shape,
scientific revision/numbering, quantities, applicable rights and complete received
scope before building a client/mapping. Public fixtures must have their own lawful
redistribution basis: an internal-use licence alone cannot qualify committed fixture
bytes. Preserve scientific support and ambiguity; no caller protein fallback or
universal curated/experimental class from the old prototypes is restored.

## Native requirements to retain independently of the stash

| Provider | Useful native statements and identity | Scope/support to qualify before implementation |
|---|---|---|
| GtoPdb | Stable target/ligand/interaction IDs, explicit species and component subunits; endogenous ligands, pharmacology, transduction/channel-property declarations. | Exact native target-to-protein links, assay/action/affinity type and units, original references, release and separate record completeness. A complex target is not one caller protein and pKi is not silently a concentration. |
| COSMIC | Native somatic variant IDs, source gene/transcript/assembly/allele representation, independent tumor/sample/cohort counts and source interpretations. | Exact module/release and genomic/transcript/protein numbering; sample denominators, unknown counts and source publication support. A count is not a frequency or clinical pathogenicity; no name-based protein attachment. |
| ASD | Source-recorded allosteric sites/modulators and separate potential-site predictions; native protein/structure/site/modulator IDs and declared conformational context. | Artifact-specific release, source residue/chain/model/sequence axis, experimental-versus-calculated basis and original assay/reference support. Archived script names release 5.1 site/PPI and 5.01 protein XML/potential-site artifacts; those names are historical pointers, not a current-release assertion. |
| BioCyc | Native organism/database frames for genes/proteins, reactions, pathways and participants, with explicit source relationships. | Exact organism/database/release, source frame links, reaction direction/participant roles, quantities/conditions and references. Open versus Limited Databases and session/subscription rights are separate; a pathway name does not attach it to a caller protein. |
| OMIM | Independent MIM gene/locus, phenotype, inheritance, mapping-key and allelic-variant/narrative declarations. | Exact MIM record type/release, source gene/phenotype links, qualifiers/publications and variant scope. An HPO/NCBI pointer is neither an original OMIM entry nor a licence; text association is not a resolved protein identity. |
| ELM | Separate motif-class IDs/regular expressions and source-reported instances with native sequence IDs, positions, status and functional/cellular context. | Original class/instance export format, sequence revision/bounds, literal annotation status and publication support, plus the exact applicable grant. Matching a regex is a calculation, not a source-reported instance; no default curated/experimental class or caller-accession fallback. |
| CASTp/CASTpFold | Native existing-result pocket/cavity/channel IDs, lining residue/atom declarations, model/structure identity and original geometry. | Source model/assembly/sequence/chain/numbering, representative-model correspondence, probe/calculation parameters, separate solvent-accessible/solvent-excluded area and volume units, revision and raw-result support. Similar pockets do not merge identity or prove shared function; no upload or new calculation belongs to knowledge recovery. |

All routes require original artifact bytes and optional original SHA, source/kind/query
context, original retrieval time when known, an honest unknown revision when unstated,
and applicable use/retention terms. Scientific quantities use PyUnitWizard nodes;
source assertions preserve their supporting original rows/records and references.
Validate the entire received native scope before mapping or exact selection, retaining
conflicts, missing values and partial/failed/unqueried outcomes. These requirements
are maintained here even when obsolete prototype code is eventually removed.
