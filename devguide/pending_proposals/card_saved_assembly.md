# Original assembly scientific reading

`sabueso.card_exploration@5` explicitly registers
`assembly_generation_exploration_binding@1`. A bundle containing an original
`assembly_generation_exploration@1` result uses this format; older-only bundles
retain their formats and scientific verifiers. The five admitted adapters are
original structures, coverage, ligand-site, quaternary and assembly exploration.
No Card schema, source acquisition or dependency change follows.

## Original inputs and results

Saving a human topic/question/detail, filtered or ordered display, exact agent
selection or original navigation retains its captured Card, native generation @4
findings, effective options, typed cells, source membership and original input,
source, quality and explanation destinations. Generator/source/parent positions
remain separate. JSON object sorting does not reorder original native occurrences.
Factored counts keep complete factors and typed locations; missing counts remain
unavailable, not zero. Source declarations do not establish physical uniqueness,
geometry, assembly contacts or biological relevance.

Verification compares retained output with frozen original predicates in
`sabueso/core/_assembly_history_v1/` and the original presentation/selection recipe
in `card_assembly_history_v1.py`. These read sealed records, not a current Card,
scientific reader, catalog, fixture or network service. Expected results never
replace stored output. Only the explicitly generated root native SDK label may
differ from the consumer; nested source values named `sabueso_version` stay exact.
Original @1–@4 scientific modules and the prior exploration verifier remain
byte-identical. Physical scope is unchanged by adding persistence.

The genuine original live capsule predates this implementation: producer
`77fd770e4d2a8fa94eea3fbd723a84fc90875efb`, SDK `0.14.0+135.g77fd770`.
`tests/core/data/assembly_live_v1.json.gz` retains three public controls and a
legacy Card, with original wire/request/cell/frame values and source manifest.
Its frozen bytes and terms are documented in that directory's README; do not
regenerate it to make a new reader pass.

## Exact requests and navigation

Human and agent saved requests preserve normalized structure/relationship
selectors, expansion flags and positive/None operation budget. Typed selection
keeps fields, equalities, original item membership, ordering and exclusions under
`assembly_generation_access_selection@1`. Unretained requests return `not_saved`;
reading does not synthesize a new scientific answer. Older files without this
result remain `not_saved`. Raw captured Card inspection/export stays available;
`start_new()` is the explicit route to a new local interpretation.

Source assertion membership, original result/capture binding, all named rules,
typed values/states, physical limits, request identities and explanation/link
origins are checked independently. Recomputed outer hashes and a newly coherent
result identifier do not admit altered source-derived findings. Atomic bounded
agent delivery retains complete read paths when values/support/scope are deferred.
Lookup handles are access-session scoped; compare their resolved typed locations
across independent readers. Repeat saving adds no automatic support tree.

## Explanation request admission (#176)

Specialized scientific explanations previously returned before the ordinary
literal request checks; an altered `read` operation could be accepted after
resealing internal hashes, confirmed in original format @4. The shared storage
boundary now applies `scientific_explanation_request_binding@1` before each
format's frozen scientific predicates. It binds the original read operation,
empty projection/slice/outcome override, resolved target/type/size/owner, complete
capture context and result/selection identifiers. Original site/quaternary/assembly
explanations and ordinary literal body inspection remain supported. This admits
original transport consistently; it does not reinterpret historical science.
External expected digests remain a separate integrity binding, not source truth.
