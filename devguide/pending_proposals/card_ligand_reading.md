# Original structure ligand reading

The public TcTIM walkthrough exposed a delivery gap after annotation 96 → regional
structures → exact 1SUX declaration: opening `ligand_context` displayed only
`0: 5 fields` and `1: 5 fields`, despite retaining BTS/SO4 and eight original
ligand instances. The separate instance panel was readable, but reaching it
required leaving this exact declaration or rebuilding scope.

`structure_ligand_reading@1` now presents original component descriptions,
instance counts/labels, recorded chains and contacts in this same literal path.
`CardView.ligand_reading` exposes detached structured context for exact focal
ligand-list/component/instance-list/instance locations, and is `None` elsewhere.
Its complete entry records carry original typed indices and locations for
`explorer.inspect(locator=...)` and bounded `access.read(...).page(...)`.
No machine frame grows and no arbitrary container is copied for a label.
Text/HTML prepare six entries with an explicit total; the full property includes
every selected list entry in its display order while preserving original indices.
`node_entry_count` and the original node location retain complete unfiltered scope;
an empty display filter is distinct from an empty original list. Focused component
and instance details describe their whole original node. Locations do not depend
on newly registered lookup handles.

## Original semantics and compatibility

This is current optional literal delivery, like `regional_reading`, not a new
scientific adapter, stored claim or navigation rule. Original item labels,
filters, indices, support, Card bytes, quantities, native results and saved
@1–@6 verifiers remain unchanged. Existing `open()`, field selection, item
`explain()` and `back()` retain their actual original path. Independently reopened
originals receive the same current literal presentation without acquiring data,
constructing a Card or executing current scientific readers. No exploration
format or Card schema changes.

Only exact focal `has_structure` relationship nodes are admitted. Shared PDB,
component or instance labels never select another declaration. Partial, missing,
null, empty and malformed original fields retain their separate states and
inspectable original locations. A declared flag is not a scientific judgment;
literal false remains false. The retained contact mapping/minimum-distance basis
is not revalidated. These are structure-local declarations, not a regional
overlap selection, assembly membership or a statement of biological relevance.

The malformed-input control reproduced a separate existing native failure:
`ligands=False` raises `TypeError` in `structures.py` while computing
`ligands_of_interest`. [#180](https://github.com/uibcdf/sabueso/issues/180)
owns that scientific-reader robustness correction. Malformed presentation tests
use literal inspection without invoking the failing native calculation. This
does not claim to fix #180 or #173 physical assembly reconciliation.
