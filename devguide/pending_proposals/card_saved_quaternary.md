## Original result and input binding

Saving a human question/view/detail or an exact agent selection retains its
original captured Card, native @3 findings, all interface/family pairs, original
relationship IDs/annotation ordinals, source closure, rule names, request and
display membership, explanation destinations and contextual links. Source
support does not reconstruct unrecorded qualifier-level mapping lineage.
Original source versions, uncertainty, alternatives, quantities and units remain
literal. No source call, new SourceAssertion, source execution credit or Evidence
is created. No stored Card schema/shape/source registry change is needed.

Independent verification uses frozen original @3 predicates, original coordinate
admission and the original presentation recipe over retained input records. It
does not construct a current Card, call current scientific readers, consult a
producer catalog or read fixture files. Only explicitly generated rule metadata
allows a different consumer runtime version; source values and versions stay
exact. Expected verifier values never replace retained original output.

## Integrity and scope

Verification checks original native outputs, complete source membership,
captured subject, typed cells, schema/grain, request options, display exclusions,
selection identities, explanation origins and exact source/structure/annotation
destinations. Recomputed outer hashes do not admit altered scientific results,
including when a forged native output is assigned a new coherent result identity.
Independent expected digests provide an additional external integrity binding;
internal consistency alone never establishes external source authenticity/truth.

Mixed supported topics keep their own original scientific verifiers. Original
quaternary frames use the frozen compact protocol and bounded atomic deferral;
units and mandatory interpretation/source support remain inspectable. Repeated
saving without new exploration must not grow an automatic support tree.
