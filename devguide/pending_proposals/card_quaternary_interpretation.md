# Live quaternary interpretation

`explorer.answer("quaternary_interpretation")`, `view(...)` and
`explorer.access.select("quaternary_interpretation")` share one captured native
`interface_site_agreement@3` result and one explanation over that same result.
The [#165 correction](../pending_bugs/quaternary_interpretation_scope.md) owns the
science; this adapter creates no SourceAssertions, source execution or Evidence.
Browsing never fetches, refreshes or reseals the caller's Card.

## Scientific grains and original inputs

`quaternary_exploration@1` presents one classification per original interface
relationship and one comparison per interface/family field ordinal. Repeated
PDB references, declarations and annotation descriptions never merge. A valid
self-interface is a source reference finding, not a validated biological assembly.
Comparison sets and partial/uncomputed scope are exactly the native result;
geometry, affinity, biological relevance and aggregate/assembly identity are not
inferred. A positive pair does not hide another uncomputed pair.

Human rows expose kind, partner, interpretation status, coordinate status, finding
and readable reasons. Only matching stated sequence revisions establish revision
agreement. Missing entity mappings remain distinct from known fragment witnesses.
Non-text names do not establish identity or become textual display values; the
original native input remains complete. All ordinary capture validity rules apply.

`open()` retains the full native item. `explain()` presents its original source
statements and typed destinations for reference fields, request/quality context
and the complete native explanation. `related()` links exact source records,
interface/structure declarations and family indices. Missing assertion IDs remain
visible without invented destinations. Subunit text and individual assembly
declarations remain in the separate `quaternary_structure` source pane, with its
existing original saved membership.

## Compact agent contract

`quaternary_access_selection@1` applies exact textual equality, projection, explicit
member IDs and lexical ordering to the same result/item identities. These are
display choices, never scientific input selection. Invalid requests are refused;
an empty display selection is not a scientific negative.

Every included frame retains mandatory scope, actual rule names (including
canonical coordinate admission), interpretation/coordinate status, reason codes,
revision limits and complete `quaternary_support_membership@1` source membership.
Present members have exact typed record destinations; missing members have none.
Full original support/explanation locations remain available. Bounded delivery
defers values, interpretation and support atomically with explicit inspection
destinations. Cursor ownership and quantity/unit contracts remain in force.
