# Original regional chain reading

Opening one experimental structure from a regional question now presents the
original complete-chain result, each recorded chain's gap count and routes to
its full gaps and author numbering. `CardView.regional_reading` returns the same
detached structured presentation; it is `None` outside a focused regional
structural result. The selected native result and exact relationship ID own the
context. Equal PDB or chain labels never select a different declaration.

## Scientific and delivery boundary

`structure_region_reading@1` is a named presentation policy over the already
materialized original native inventory. It counts existing missing-position lists
and exposes their exact locations; it does not calculate coordinates, realign
sequences, classify a new scientific state or create SourceAssertions. The Card,
native wire, result/selection identities, quantities and historical producer
labels remain unchanged. Source-backed coordinate admission and original stated
revision limits remain visible.

An empty complete-chain list, zero gaps and uncomputed completeness are distinct.
Historical results without original coordinate admission keep their reported
values, with that missing basis explicit. No current predicate fills their gaps.
Literal lookalikes do not receive this scientific presentation. Text/Jupyter show
at most six chain rows, with an explicit omitted count; all rows and full original
gap lists remain reachable. Preparing a preview only builds those six chain
details, rather than registering locations for every undisplayed chain. The full
property remains unlimited; `chain_count` and `chains_complete` state its scope.
Lookup handles are local delivery addresses and can
differ across independent readers of the same original values.

Compact machine frames stay unchanged: callers can read `complete_chains`,
`missing_in_region` and `author_numbering` from the existing exact item location
through bounded `CardAccess.read(...).page(...)`. The optional human summary
does not duplicate those values into every machine response or force a larger
response budget. The human property's locations address those same original
fields. No stored format, schema, source query or shared MOLI contract changes.
Saved regional details retain their original request, result, support and
navigation; current readable presentation performs no new scientific evaluation.
