# Human ligand-site comparison exploration

`explorer.view("ligand_site_comparisons")` and its question alias present one
retained protein–ligand contact declaration per row. They reuse the existing
`ligand_sites()` result and native explanation without changing scientific rules,
source assertions, Card schema, quantity contracts or packet mappings. No source
acquisition, alignment, physical contact calculation or identity merge occurs.

## Shared captured result and original support

The `ligand_site_exploration@1` presentation reads one captured Card, caches its
native result and original explanations, and shares them with later display,
selection, source reading and literal machine pages. A private native explanation
helper accepts that same precomputed view; the public explanation remains equal.
Rows retain full native values and direct support/explanation locations. Result
identity excludes only the generated classification producer label; original
stored fields and source versions remain intact. Returned values are defensive
copies and later mutable Card changes do not affect the capture.

Readable finding/context cells preserve computed, partial and uncomputed outcomes.
Unknown comparison never becomes a negative overlap. Unstated revisions never
establish agreement, and sequence overlap does not establish atomic proximity.
Every original canonical, annotation and contact input source stays inspectable;
missing references remain visible gaps. Coverage is a separate original
source/request question, not inferred from a displayed empty table.

## Exact contextual navigation

`item.explain()` opens original input statements and retains the complete native
explanation. `related()` offers exact original source, annotation and contact
locations with return navigation. `ligand_site_context_links@1` adds retained
structure, instance and assembly context. Structure-local instances require an
exact focal subject and the same source-declared PDB component; original ligand
and instance list indices keep repeated labels distinct. This is contextual
navigation only: it never equates an aggregate declaration with one physical
occurrence, infers stoichiometry or projects contacts into an assembly. Foreign
structure subjects cannot offer focal instance/assembly links. Original structure
records and all native context remain inspectable without being reclassified.
Conflicting structural qualifiers stay in original support and have visible
context-link labels; navigation does not resolve them. Physical distance
quantities retain their negotiated value/unit representation.

## Explicit incomplete scope

This first pane has complete native reading, string display filters/sorts,
source/back navigation, text/HTML presentation and bounded literal `access.read()`.
Specialized machine `select()` remains structural only. Saved comparison
verification is not yet implemented: the new nonliteral result, explanations,
links and originating navigation refuse saving, while unrelated original literal
and existing saved routes remain usable. Old saved sessions report this topic
and question as `not_saved` and never execute current scientific readers.

These agent/saved extensions, assembly-specific reconciliation, region/model
transitions, workload budgets and actual researcher acceptance remain required
under the [complete 0.15.0 inventory](card_exploration_completion_0150.md). This
bounded pane does not close #148 or resume candidate selection/publication.
